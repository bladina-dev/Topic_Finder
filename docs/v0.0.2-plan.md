Working system: Tavily + Google Trends scanning → Gemini generation with 3 creative formats → 6 psych triggers (Gulf-specific) → 6-dimension benchmark (best: 52/60) → ChromaDB brand ingestion → FastAPI + React + CLI + basic scheduler.

> [!NOTE]
> **Design decision:** Sources stored as **CSV files** in `sources/` — editable in Excel, Google Sheets, or any text editor. No YAML/JSON knowledge required from the marketing team.

```csv

tech,domain,magnitt.com,MAGNiTT
finance,twitter,@Argaam,Argaam
finance,domain,argaam.com,Argaam Financial
lifestyle,instagram,@saudistyle,Saudi Style
```

### Priority 2: Telegram + GitHub Actions (Zero Infrastructure)

> [!IMPORTANT]
> **Design decision:** No server needed. GitHub Actions handles scheduling (cron) and command dispatch (webhook). Telegram bot is a simple send-only module — no long-running listener process required.

#### [NEW] [telegram_bot.py](file:///Users/mohamedsalah/Documents/antigravity/marketing-agent/src/telegram_bot.py)
- Uses `python-telegram-bot>=21.0`
- **Send-only functions** (called by pipeline, not a persistent listener):
  - `send_report(report)` → formatted Telegram message with simplified scores
  - `send_top_angles(angles)` → top 3 angles with 🔥/✅/⚠️ labels
  - `send_text(text)` → raw text message
  - Handles 4096 char limit (splits into chunks)
- **Webhook handler** (triggered by GitHub Actions `repository_dispatch`):
  - `handle_command(command)` → routes `/today`, `/sources`, `/status`

#### [NEW] [report_writer.py](file:///Users/mohamedsalah/Documents/antigravity/marketing-agent/src/report_writer.py)
- `simplified_grade(total_score)` → converts 6-dimension totals to:
  - **🔥 Fire** (total ≥ 48) — Ready to post
  - **✅ Good** (total ≥ 36) — Needs minor editing
  - **⚠️ Weak** (total < 36) — Skip or rework
- `format_telegram_report(output, benchmark)` → Telegram-formatted text
- `save_markdown_report(output, benchmark)` → structured `.md` file
- `save_html_report(output, benchmark)` → standalone HTML with inline CSS
- `save_json_report(output, benchmark)` → raw JSON
- Reports saved to `reports/YYYY-MM-DD_HHMM_{grade}.{md,html,json}`

#### [NEW] `.github/workflows/scheduled_run.yml`
- **Cron trigger:** Runs at 03:00 UTC and 15:00 UTC (= 6 AM and 6 PM Cairo/Riyadh)
- **Steps:** checkout → setup Python + uv → install deps → run pipeline → benchmark → send Telegram report
- **Secrets required:** `GOOGLE_API_KEY`, `TAVILY_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`

#### [NEW] `.github/workflows/telegram_command.yml`
- **Trigger:** `repository_dispatch` (event type: `telegram-command`)
- Allows marketing team Telegram commands to trigger runs via a lightweight webhook
- Supports `/today` → dispatches a fresh pipeline run

#### [NEW] `scripts/run_and_report.py`
- Standalone entrypoint for GitHub Actions: run pipeline → benchmark → save reports → send Telegram
- Exit code 0 on success, 1 on failure (for GitHub Actions status)
