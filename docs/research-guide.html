1. Voiceover — Azure vs Alternatives

Azure TTS is now wired up (ar-SA-HamedNeural). Before testing, answer these:

Does the Saudi Arabic voice sound natural enough for YouTube Shorts, or does it sound robotic?
Do you want a male or female voice? Azure has both: ar-SA-HamedNeural (male) and ar-SA-ZariyahNeural (female).
Should the voiceover read the full script or just the hook + key points?
Test Azure TTS output quality before committing to it long-term.

If Azure sounds robotic — alternatives to research

ElevenLabs~$5/mo starter. Best Arabic naturalness. Research: do they have a Gulf dialect voice?
Play.htHas Arabic. Research: voice quality vs Azure for Saudi dialect.
OpenAI TTSNo Arabic yet as of 2026. Research: has this changed?
Google Cloud TTSHas ar-XA Wavenet. Research: quality vs Azure, cost per character.

2. Background Music — What to Use Instead of MiniMax

MiniMax music generation is skipped (no key). Videos currently assemble without background music.

Is background music actually needed for the Shorts to perform well, or can you launch without it?
Are there royalty-free Arabic/Gulf music libraries that work for YouTube without copyright strikes?

Options to research

Static libraryDownload 5–10 royalty-free tracks, rotate them. Free, no API. Research: YouTube-safe Gulf music sources.
YouTube Audio LibraryFree, YouTube-safe. Research: does it have Arabic/Gulf style tracks?
Suno AIAI music generation. Research: API availability, cost, Arabic style support.
MiniMaxAlready wired. Research: pricing, how to get an API key.
Easiest path: download 5 royalty-free tracks into assets/music/ and rotate them. No API needed.

4. Video Rendering — Is Remotion Practical in GitHub Actions?

The pipeline generates Remotion JSON. Actual MP4 rendering requires a Node.js + Chrome environment.

Is Remotion rendering actually happening in GitHub Actions, or is the JSON just saved locally?
How long does a Remotion render take? Does it fit in the 15-minute GitHub Actions timeout?
Does the ubuntu-latest GitHub Actions runner have enough RAM for Remotion + Chrome headless?

Alternatives if Remotion is too heavy for CI

Remotion LambdaRender in AWS Lambda. Research: cost per render, setup complexity.
FFmpeg templatesPre-built video templates, overlay text with FFmpeg. No browser needed. Much faster.
Shotstack APICloud video rendering API. Research: Arabic text support, cost per render.

7. Memory — Should the Agent Learn From Past Runs?

Currently stateless — every run starts fresh with no knowledge of what was generated before.

Are the same trends being re-discovered across runs? (Check past Telegram reports for duplicates.)
Should the agent remember which angles scored well and avoid similar ones?
Memory Hub v5 is already running — can Topic Finder be connected to it?

What connecting to Memory Hub would give you

  • No duplicate trend angles across runs
  • Track which angles were approved/rejected and learn from that
  • Brand voice consistency across sessions
  • A history of what worked — feeds back into psychology engine
Research: what would it take to call Memory Hub from pipeline.py? The API is already at http://localhost:8000/api/v1/memory.

8. API Costs — What Is This Costing Per Run?

With 5-minute scheduling (288 runs/day), costs could be significant. Need to know before scaling.

How many Tavily credits does one pipeline run use? (Check Tavily dashboard.)
How many Gemini tokens per run? (Check Google Cloud console.)
What is the Azure TTS cost per voiceover? (Azure charges per character.)
At Phase 2 (10×/day) and Phase 3 (4×/day), what is the monthly cost?

Cost estimates to calculate

Per run (estimate):
  • Tavily: ~10 searches × $0.01 = ~$0.10
  • Gemini 2.5 Flash: ~50K tokens × free tier = $0
  • Azure TTS: ~500 chars × $0.000016 = ~$0.008
  • Total: ~$0.11/run
Monthly at each phase:
  • Phase 1 (288/day): ~$950/mo ⚠️
  • Phase 2 (10/day): ~$33/mo
  • Phase 3 (4/day): ~$13/mo ✅
Verify actual Tavily + Gemini costs from dashboards. Phase 1 (5-min) is likely unsustainable past a few days of testing.
Long Term

9. Infrastructure — GitHub Actions Forever?

GitHub Actions is great for testing but has limits: 15-min timeout, no persistent state, cold start every run.

Is the 15-minute GitHub Actions timeout enough for a full pipeline run with video assembly?
When the agent grows (more sources, memory, video rendering), will GitHub Actions still work?

Alternatives to research when ready

Railway / RenderAlways-on Python server with APScheduler. No cold start. Research: cost for a 512MB instance.
Fly.ioFree tier with 3 shared VMs. Research: can it run Remotion rendering?
Self-hosted (your machine)Already running locally. Use the built-in APScheduler (scheduler.py). Zero cost. Downside: only works when machine is on.
