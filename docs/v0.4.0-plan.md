## Changes

### 1. `pyproject.toml`
- Bump version: `0.2.0` → `0.3.0`
- Replace `google-generativeai>=0.8.0` with `google-genai>=1.0.0`

### 2. `src/ai_orchestrator.py`
**Gemini migration:**
- Remove `import google.generativeai as genai`
- Use `from google import genai` + `from google.genai import types`
- Replace `genai.configure(api_key=...)` + `genai.GenerativeModel(...)` pattern
  with `genai.Client(api_key=...)` + `client.models.generate_content(...)`
- New call: `client.models.generate_content(model="gemini-2.5-flash", contents=user_prompt, config=types.GenerateContentConfig(system_instruction=system_prompt))`

**Claude model fix:**
- Update `claude-sonnet-4-20250514` → `claude-sonnet-4-6` (correct current model ID)

**Parse error fix:**
- Handle ````json` code fence prefix (strip language tag after opening fence)
- On parse failure, log first 500 chars of raw response for debugging

**Banned patterns expansion (ANGLE_GENERATION_PROMPT):**
- Add: `"overcoming adversity narrative"`, `"the hero entrepreneur"`, `"hidden gem"`, `"What X% of [Audience] Know"`, `"underdog outperforms"`, `"إشارة خفية"`, `"3 أشياء"`, `"الأرقام تقول شيء ثاني"`, `"تسبح مع التيار"`, `"سر الذي خرب"`

### 3. `src/config.py`
- Add `google_trends_enabled: bool = False`
  (defaults off — broken until pytrends fixes Google's 404 or alternative is found)

### 4. `src/trend_scanner.py`
- Gate `scan_google_trends()` call behind `settings.google_trends_enabled`
- Log a one-time info message when disabled: `[TrendScanner] Google Trends disabled (google_trends_enabled=False)`
